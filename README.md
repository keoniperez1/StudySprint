## Summary

This document provides an overview, project spec, and wireframes for my capstone project: **StudySprint**, a mobile study planner designed to help students stay organized, manage assignments, practice with flashcards, and test their knowledge through interactive quizzes.

The goal of StudySprint is to make studying easier by combining multiple study tools into one simple Android application. Students will be able to track their academic tasks, review important concepts, and practice answering questions.

## Notes

I am completing this project individually.

For Milestone 1, I focused on planning and designing StudySprint, including defining its main features, identifying its target audience, and selecting an API.

The app's main features will include:

- **Study Planner:** Add, organize, and complete study tasks.
- **Flashcards:** Create and review flashcards to memorize important concepts.
- **Practice Quizzes:** Answer multiple-choice questions and review quiz results.
- **Progress Tracking:** Monitor completed tasks and quiz performance.

I selected the **Open Trivia Database API** to provide multiple-choice questions for the quiz feature.

The initial version of StudySprint will focus on essential features that can be completed within the project timeline. Additional features, such as study reminders, streak tracking, and customization, may be implemented if time allows.

The next step will be developing the Android application using Kotlin and Android Studio.
